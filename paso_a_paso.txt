Resumen de todo lo que hiciste paso a paso en tu proyecto

Paso 1: Abrir Git y revisar el proyecto
Primero abriste la terminal de Git dentro de la carpeta Github1 en tu escritorio para revisar cómo estaba el proyecto y ver el historial de cambios que ya tenías guardados.

Paso 2: Conectar tu carpeta con GitHub
Ubicaste la dirección de tu repositorio en la nube (https://github.com/miguelproject425/GitHub.git) y revisaste que tu computadora estuviera enlazada correctamente a ese enlace.

Paso 3: Iniciar sesión con tu Token de acceso
Para que GitHub te permitiera subir archivos de forma directa y segura, generaste un Token de Acceso Personal (PAT) en tu cuenta y lo configuraste para autorizar las subidas.

Paso 4: Hacer tu primera subida (Push)
Con la conexión lista, subiste por primera vez la rama principal (main) para que tu repositorio en GitHub quedara activo con tus primeros archivos.

Paso 5: Crear una tienda online completa que funcione
Construiste una tienda de tecnología interactiva (NEXUS TECH) usando tres tecnologías:
- index.html: Toda la estructura de la página (buscador, categorías de productos, botón del carrito, ventana de pago y detalles de los artículos).
- style.css: El diseño visual moderno con modo oscuro, luces de neón, animaciones y adaptación para que se vea bien tanto en computadoras como en celulares.
- app.js: Todo el funcionamiento real (filtrar productos, buscador en tiempo real, agregar o quitar productos del carrito, guardar lo que compras en la memoria del navegador, aplicar cupones de descuento y simular el pago con factura).
- README.md: El manual con la descripción y funciones del proyecto.

Paso 6: Guardar y enviar la tienda a GitHub
Empaquetaste todos los archivos nuevos, creaste un commit para registrar los cambios y los enviaste a GitHub para que tu tienda quedara guardada en internet.

Paso 7: Crear varias ramas de trabajo
Para organizar mejor tu proyecto como en un entorno profesional, creaste y subiste 4 ramas nuevas:
- develop: Para ir probando nuevas ideas antes de publicarlas.
- feature/payment-gateways: Para agregar más métodos de pago en el futuro.
- feature/dark-mode-enhancements: Para hacer mejoras de diseño.
- hotfix/cart-optimization: Para corregir detalles del carrito rápidamente.

En conclusión: Comenzaste abriendo Git en tu máquina, lo conectaste a tu cuenta de GitHub, creaste una tienda online moderna y funcional, y dejaste todo guardado y ordenado con diferentes ramas en la nube.
